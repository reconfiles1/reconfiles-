ℹ This tool adds new text on top of your PDF. To replace existing text, place a cover box (auto-coloured to match the background) over the old text, then type the replacement on top. It can't re-flow or directly edit text embedded in the original file — for heavily designed documents, editing the source and re-exporting gives the cleanest result. Note that covered text is hidden visually but remains in the file's text layer underneath, so don't rely on this to redact sensitive information.
